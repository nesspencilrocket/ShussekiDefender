# 出席ディフェンダー（Shusseki Defender）（制作中）

授業へ向かう学生たちを妨害し、**出席させない**ことを目指す 2D タワーディフェンスゲームです。
Unity 6 で制作しています。

プレイヤーは「出席ディフェンダー」。キャンパスの通路に妨害装置を設置し、
授業終了まで学生を教室にたどり着かせないようにします。
妨害に成功するほどスコアが上がり、学務課から言い渡される**処分**が重くなります。
重い処分ほど良い結果、という逆転した評価がこのゲームの特徴です。

## ゲームの概要

| 項目 | 内容 |
|---|---|
| ジャンル | 2D タワーディフェンス |
| 舞台 | 大学のキャンパス（1限目〜6限目） |
| 目的 | 制限時間が尽きるまで、学生をゴール（教室）に通さない |
| 敗北条件 | ゴールに到達した学生の人数が、ステージごとの上限に達する |
| 勝利条件 | 制限時間を耐え切る |
| 評価 | スコアに応じて「訓告」〜「退学処分」の 5 段階の処分が決まる |
| ステージ数 | 6（1限目〜6限目。前の時限をクリアすると次が開放される） |

学生はマップ外の 13 か所の入口から湧き、通路を通って画面上部の校舎へ向かいます。
同じ入口から出た学生が一列に並ばないよう、湧いた直後に一定の確率で近くの別の経路へ乗り換えます。

## 遊び方

### 基本の流れ

1. タイトル画面で「妨害開始」を押す
2. ステージ選択画面で時限（1限目〜6限目）を選ぶ。説明文と紹介動画が表示される
3. 「妨害開始！」を押すとステージが始まる
4. 「3・2・1・GO!」のカウントダウンの後、学生が湧き始める
5. 制限時間を耐え切ればクリア、通過人数が上限に達すれば失敗
6. 結果画面でスコアと処分を確認し、「次の時限へ」「Retry」「Title」から選ぶ

### 操作方法

操作はすべてマウスで行います。

| 操作 | 内容 |
|---|---|
| 空いている設置スポットをクリック | 妨害装置の購入画面が開く。装置を選ぶとコインを払って設置される |
| 設置済みの装置をクリック | 強化・売却の画面が開く。攻撃範囲も表示される |
| 強化ボタン | コインを払って攻撃力と連射速度を上げる（最大 5 レベル。強化のたびに費用が 10 上がる） |
| 売却ボタン | 装置を取り外し、次の強化費用の半額を受け取る |
| 倍速ボタン（右下） | ゲーム速度を ×1.0 と ×1.5 で切り替える |

設置スポットはマップ上に 10 か所あります。カウントダウン中は設置・強化はできません。

### コイン

- ステージ開始時に初期コインを持っています（ステージにより 100〜150）
- 学生を 1 人倒すごとに 10 コイン手に入ります
- コインは装置の購入・強化に使います。使わずに残したコインはスコアに加算されます

## ステージ一覧

時限が進むほど、制限時間が長く、湧く学生が多く、許される通過人数が少なくなります。
背景の色合いも時限に合わせて朝から夕方へ変わります。

| 時限 | 制限時間 | 通過の上限 | 初期コイン | 湧く人数（5 ウェーブ） | 説明 |
|---|---|---|---|---|---|
| 1限目 | 30 秒 | 50 人 | 100 | 5 / 10 / 20 / 30 / 200 | 朝いちばんの授業。登校してくる学生はまだ少ない。 |
| 2限目 | 40 秒 | 45 人 | 100 | 8 / 14 / 26 / 40 / 220 | 目が覚めた学生が増えてきた。 |
| 3限目 | 50 秒 | 40 人 | 120 | 10 / 18 / 32 / 50 / 240 | 昼が近く、人通りがいちばん多い時間帯。 |
| 4限目 | 60 秒 | 35 人 | 120 | 12 / 22 / 38 / 60 / 260 | 昼食を終えた学生が一斉に動きだす。 |
| 5限目 | 70 秒 | 30 人 | 150 | 14 / 26 / 44 / 70 / 280 | 西日が差しこむ時間。ここまで来た学生は諦めが悪い。 |
| 6限目 | 90 秒 | 25 人 | 150 | 16 / 30 / 52 / 84 / 320 | 最後の講義。日が暮れるまで一人も通さなければ、今日の勝ちだ。 |

ステージの数値は `Assets/ScriptableObject/Stages/Stage_N.asset`（`StageData`）にまとめてあり、
シーンを触らずに調整できます。6 つの時限は同じ `Stage_1` シーンを使い、`StageData` を差し替えて切り替えています。

## スコアと処分

### スコアの計算

```
スコア = 倒した学生の数 × 50 ＋ 残ったコイン × 1 ＋ 経過秒数 × 10
```

### 処分の判定

クリアすると、スコアに応じて学務課から処分が言い渡されます。
**妨害する側なので、重い処分ほど良い結果**です。失敗した場合は「処分なし」になります。

| 処分 | 1限目 | 2限目 | 3限目 | 4限目 | 5限目 | 6限目 |
|---|---|---|---|---|---|---|
| 訓告 | 0〜 | 0〜 | 0〜 | 0〜 | 0〜 | 0〜 |
| 厳重注意 | 800〜 | 1,000〜 | 1,300〜 | 1,600〜 | 1,900〜 | 2,400〜 |
| 1週間停学 | 1,400〜 | 1,800〜 | 2,300〜 | 2,800〜 | 3,300〜 | 4,200〜 |
| 無期限停学 | 2,000〜 | 2,600〜 | 3,300〜 | 4,000〜 | 4,700〜 | 6,000〜 |
| 退学処分 | 2,600〜 | 3,400〜 | 4,300〜 | 5,200〜 | 6,100〜 | 7,800〜 |

各時限のベストスコアは保存され、タイトル画面の「成績確認」でいつでも見られます。

## 妨害装置（武器）

| 装置 | 購入費用 | 攻撃力 | 射程 | 発射間隔 | 強化費用（初回） |
|---|---|---|---|---|---|
| 通常の装置 | 20 | 2 | 2 | 0.5 秒 | 50 |
| 強力な装置 | 30 | 8 | 8 | 2 秒 | 60 |

- 通常の装置は射程が短いぶん連射が速く、近くを通る学生に強い
- 強力な装置は射程が長く一発が重い。遠くの学生まで届く
- どちらも、射程内の学生のうち**ゴールにいちばん近い学生**を優先して狙う
- 強化すると攻撃力が上がり、発射間隔が短くなる。強化するたびに次の費用が上がる

## 画面構成

| シーン | 内容 |
|---|---|
| `StartMenu` | タイトル画面。「妨害開始」「成績確認」「設定」 |
| `StageSelect` | 時限の選択。未開放の時限は押せない。選ぶと説明文と紹介動画が出る |
| `Stage_1` | ゲーム本編。6 つの時限すべてでこのシーンを使う |
| `Records` | 成績確認。時限ごとのベストスコア・処分・次の処分までの点数、合計スコア |
| `Settings` | 設定。全体の音量・BGM の音量・画面の明るさ・ゲーム速度 |

設定と進行状況（開放済みの時限・ベストスコア）は `PlayerPrefs` に保存されます。

## 動作環境・プロジェクトの開き方

### 必要なもの

| 項目 | バージョン |
|---|---|
| Unity | **6000.2.7f2**（Unity 6） |
| レンダーパイプライン | Universal Render Pipeline（2D Renderer） 17.2.0 |
| 入力 | Input System 1.14.2 |
| Git LFS | 必須（`*.asset` を LFS で管理しているため） |

### 手順

```bash
git lfs install
git clone https://github.com/nesspencilrocket/ShussekiDefender.git
```

1. Unity Hub で「Add project from disk」からクローンしたフォルダを開く
2. `Assets/Scenes/StartMenu.unity` を開いて再生する

Git LFS を入れずにクローンすると、ステージ設定やフォントのアセットが中身の無いポインタファイルになり、正しく動きません。

## フォルダ構成

```
Assets/
├── Scenes/               シーン（StartMenu / StageSelect / Stage_1 / Records / Settings）
├── Scripts/
│   ├── system/           ゲーム進行・湧き・ステージ定義・UI 部品・設定
│   ├── enemy/            学生（敵）の移動・HP・データ定義
│   ├── Weapons/          妨害装置・弾・強化
│   ├── StartMenu/        タイトル・成績確認・設定画面
│   ├── StageSelect/      ステージ選択画面
│   └── (Camera, Node, Timer, MusicScript)
├── ScriptableObject/     ステージ定義（StageData）と武器定義
├── Prefabs/              学生・装置・弾・設置スポット
├── ImageALL/             タイトル・背景・ボタンの画像
├── TowerDefenseMaterials/ ドット絵素材
├── Music/                BGM・ジングル
├── Video/                ステージ選択画面の紹介動画
└── Animetions/           学生のアニメーション
```

## 開発状況

- タイトル・ステージ選択・本編・結果画面・成績確認・設定の一連の画面
- 6 時限分のステージ定義と、クリアによる順次開放
- 13 か所の入口からの湧きと、経路の乗り換え
- 2 種類の妨害装置の購入・強化・売却
- スコアと 5 段階の処分判定、ベストスコアの保存
- 音量・明るさ・ゲーム速度の設定

### 予定

- 学生の種類を増やす（自転車・学務課）
- プレイヤーの必殺技（臨時休講・教授の急病）
- 時限ごとのマップ
